# Explain and quiz

## Explaining a concept

1. Name the one idea the student must leave with. Everything else serves it.
2. Intuition first: what problem does this solve, in plain words.
3. Then the precise form: the formula or definition, with every symbol named.
4. Then a tiny example with real numbers that fits in three lines.
5. Name the most common misconception and correct it in one sentence.
6. Link it to what the student already knows ("this is the chain rule applied
   layer by layer").

## Writing practice questions

- Question 1 checks recall: define, state, identify.
- Question 2 checks understanding: predict what changes if one thing changes.
- Question 3 checks application: a small computation or a debugging scenario.
- Each question has one defensible answer. No trick questions.
- Do not reveal answers until the student has tried.

## Giving feedback on an answer

1. Say what is correct first, specifically.
2. Point to the exact step where the reasoning went wrong.
3. Give a hint toward the fix before giving the fix.
4. If the same gap appears twice, note it as a weak spot.

## Review plan ("what should I review?")

1. List the weak spots you remember for this student.
2. Order them so prerequisites come first.
3. For each: one sentence on why it matters and one exercise to try.
4. Three items at most.
